# 실습과제

## 1. 메모리 누수를 설명하라.

프로그램이 동적으로 할당한 메모리를 사용 후 해제하지 않아 해당 메모리가 프로그램 종료 전까지 계속 점유된 상태로 남는 있는 것을 의미한다.

---

## 2. 메모리 누수가 왜 심각한 문제를 발생시키는지 설명하라.

1) **성능 저하**  
사용하지 않는 메모리가 계속 쌓이면 사용할 수 있는 메모리가 줄어들고 프로그램 그에 따라 프로그램 속도가 느려진다.

2) **프로그램 비정상 종료**  
메모리가 부족해지면 프로그램이 강제 종료 될 수 있다.

3) **시스템 전체 영향**  
특히 서버나 장시간 실행 프로그램에서 메모리가 누적 되면 시스템 전체가 느려지거나 다운될 수 있다.

결론적으로 메모리 누수를 방치하면 프로그램에 치명적인 손상을 줄 수 있다.

---

## 3. 메모리 누수를 방지하는 방법을 설명하라.

메모리 누수를 방지하는 방법으로 아래 5개와 같은 방법들이 있다.
1) **할당 후 delete로 반드시 해제**
2) **배열은 delete[]로 해제**
3) **포인터 초기화**
4) **사용 후 nullptr로 설정**
5) **스마트 포인터 사용(자동으로 메모리 해제)**

---

## 4. C++ 스마트 포인터 클래스에 대해 조사하라

스마트 포인터는 `<memory>`헤더에 포함되며 자동으로 메모리를 관리해주는 객체이다. (메모리 해제를 자동으로 해준다.)

| 스마트 포인터 | 소유권 | 특징 | 주요 용도 |   
|---|---|---|---|   
| unique_ptr | 단독 | 복사 불가(move만 가능) | 일반적인 단일 소유, 가장 많이 사용 | 
| shared_ptr | 공유 | 복사 가능 | 여러 곳에서 동일 객체 공유, 참조 카운팅(0이 되면 자동 삭제) |  
| weak_ptr | 없음 | 복사 가능 | 순환 참조 방지, shared_ptr 보조용 |
