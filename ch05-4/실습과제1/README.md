# 실습과제

## 1. 일반생성자와 복사생성자의 차이는?    

**일반생성자**     
객체를 처음 만들 때 값을 초기화하는 생성자

**복사생성자**        
기존 객체를 이용해서 새로운 객체를 만들 때 호출되는 생성자    

---

## 2. 대입연산과 얕은 복사생성자의 차이는 무엇인가?

**대입연산**     
이미 존재하는 객체의 값을 대입할 때 사용하고 기존 객체의 메모리에 덮어쓴다.

**복사생성자**      
원본 객체의 값을 복사하여 생성하고 클래스에 오직 한 개만 선언 가능하다. 그리고 복사 생성자는 보통 생성자와 클래스 내의 중복 선언이 가능하다.     
얕은 복사시에는 포인터가 있으면 같은 메모리를 공유하기 때문에 하나의 값을 바꾸면 복사된 객체도 값이 바뀌게 된다. (같은 주소를 가르킴)

결론적으로, 복사 생성자는 이미 존재하는 객체를 이용해 새로운 객체를 만들 때 호출되어 새 객체의 메모리를 초기화하고,
대입 연산은 이미 만들어져 있는 객체에 다른 객체의 값의 데이터를 교체할 때 사용된다.
