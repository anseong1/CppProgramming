# 실습과제


## 1. 참조에 의한 호출과 주소에 의한 호출의 차이점을 설명하라.
두 방식 모두 함수 외부의 변수를 함수 내부에서 수정할 수 있게 해주지만 문법과 동작 방식에 차이가 있다.     

**값에 의한 호출(Call by Value)**     
- 포인터(*) 를 매개변수로 사용
- 호출 시 & 연산자로 주소를 명시적으로 전달
- 역참조(*x)로 값에 접근
- NULL 전달 가능 → 위험성 존재
- C, C++ 에서 사용     

**참조에 의한 호출(Call by Reference)**         
- 참조(&) 를 매개변수로 사용
- 호출 시 일반 변수처럼 그대로 전달
- 변수처럼 직접 접근 (x)
- NULL 참조 불가 → 더 안전
- C++, Java, Python 등에서 사용

---

## 2. 참조에 의한 호출의 장점은 무엇인가?

**1. 안전성**
- `NULL` 참조가 불가능하여 **널 포인터 역참조 오류** 방지
- 참조는 반드시 유효한 변수를 가리켜야 함

**2. 가독성**
- 호출 시 `&` 연산자 불필요 → 코드가 **간결하고 직관적**
- 함수 내부에서 역참조(`*`) 없이 변수처럼 바로 사용 가능

**3. 성능**
- 큰 객체나 구조체를 복사하지 않고 전달 → **메모리 절약**
- 복사 비용 없이 원본에 직접 접근 가능

**4. 불변성 보장 (`const` 참조)**
- `const &`를 사용하면 원본을 수정하지 않으면서도 복사 없이 전달 가능
- 성능과 안전성을 동시에 확보
