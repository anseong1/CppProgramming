# 실습과제

## 소스코드설명

```
#include <iostream>
```
- 입출력을 위한 헤더파일이며 cout,endl 등을 사용하기 위해 선언

```
int main(void)
```
- 메인함수 시작점

```
std::cout << "Hello";
```
- 화면에 Hello를 출력, ``cout``은 std 네임스페이스 안에 선언된 표준 출력 객체

```
return 0;
```
- 0을 반환하고 프로그램 종료
