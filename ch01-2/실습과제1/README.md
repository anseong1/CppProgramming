# 실습과제

## 1. IDE란 무엇인가?
IDE는 프로그래밍에 필요한 도구들을 하나로 묶어놓은 프로그램이다.   
코딩을 하려면 보통 코드 편집기, 컴파일러, 디버거 등 여러 도구가 필요하다. IDE는 이것들을 따로따로 쓰지 않아도 되게 한 곳에 다 모아놓은 것이다.

---

## 2. IDE의 종류에 대하여 조사하시오.
- Visual Studio Code : 웹 개발(HTML, CSS, JavaScript), Node.js 개발, Python 개발, 다양한 언어 범용 개발
- Visual Studio :  C, C++, C#, .NET 개발
- IntelliJ IDEA : Java 개발, Spring 프레임워크 개발
- Eclipse IDE : Java 애플리케이션 개발
- PyCharm : Python 프로그램 개발, 데이터 분석, 머신러닝 및 AI 개발

---

## 3. IDE에 포함된 기능은 무엇인가?
**코드편집기(Code Editor)**      
코드를 작성하는 공간이다. 단순한 메모장과 달리 문법에 따라 색을 다르게 표시해주고, 코드를 자동으로 완성해주는 기능도 있다. 덕분에 오타나 문법 오류를 미리 잡을 수 있다.    

**컴파일러(Compiler) / 인터프리터(Interpreter)**     
작성한 프로그램을 실행할 수 있도록 컴퓨터가 이해할 수 있는 형태로 변환하거나 실행하는 기능이다.
컴파일러는 소스 코드를 기계어로 변환하고, 인터프리터는 코드를 한 줄씩 해석하여 실행한다.        

**디버거(Debugger)**      
코드에서 오류가 발생했을 때 어디서 문제가 생겼는지 찾아주는 도구이다. 코드를 한 줄씩 실행하면서 변수 값이 어떻게 바뀌는지 확인할 수 있어서 오류를 찾기가 훨씬 쉽다.
