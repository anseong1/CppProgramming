# 실습과제

## 1. 다음빈칸을채우시오.정적(static)변수는 인터넷을 검색하여 조사해볼 것

| 변수의 종류 | 메모리 영역 | 메모리 할당시점 | 메모리 해제시점 |
|------------|------------|---------------|---------------|
| 지역변수 | 스택(Stack) | 함수 호출 시 | 함수 종료 시 |
| 전역변수 | 데이터(Data) 영역 | 프로그램 시작 시 | 프로그램 종료 시 |
| 정적변수 | 데이터(Data) 영역 | 처음 선언/초기화 시 | 프로그램 종료 시 |
| 동적메모리 | 힙(Heap) | malloc/new 호출 시 | free/delete 호출 시 |
