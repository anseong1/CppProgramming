# 실습과제

## 1. 매크로상수 NULL이 무엇인지 조사하라, C/C++언어에서 정의의 차이, 정의된 헤더파일, 사용용도 등

NULL은 포인터가 아무것도 가리키지 않는다는 것을 나타내는 매크로 상수이다. C에서는 ``((void *)0)``으로 정의되어 있어 void 포인터 형태의 0이고, C++에서는 단순히 정수 ``0``으로 정의된다.
NULL이 정의된 헤더파일은 ``<stddef.h>``(C) 또는 ``<cstddef>``(C++)에서 정의되는 것이 표준이며
<stdio.h>, <stdlib.h> 등 여러 표준 라이브러리 헤더에서도 간접적으로 포함되어 사용할 수 있다. 주로 포인터를 선언할 때 초기값으로 설정하거나, 포인터가 유효한지 검사할 때 또는 함수 실패 시 반환값으로 사용한다.

---

## 2. 널문자와 NULL의 차이를 설명하시오, 정의, 자료형, 메모리크기, 실제값, 사용용도 등

| 구분     | 널문자 (`'\0'`)    | NULL               |
| ------ | --------------- | ------------------ |
| 정의     | 문자열의 끝을 나타내는 문자 | 포인터가 아무 것도 가리키지 않음 |
| 자료형    | char          | 포인터 관련 값           |
| 실제 값   | 0 (아스키 코드)      | 0 또는 (void*)0    |
| 메모리 크기 | 1바이트            | 포인터 크기 (4 또는 8바이트) |
| 사용 용도  | 문자열 종료          | 포인터 초기화            |

예를 들어, "Hello"라는 문자열은 메모리에 H, e, l, l, o, '\0' 순서로 저장되는데 마지막의 '\0'이 널문자이다. int형 포인터 변수를 선언하면서 NULL로 초기화하면 해당 포인터는 어떤 변수의 주소도 가리키지 않는 상태가 된다. 

## 3. 요즘은 NULL 대신에 nullptr을 사용하는데 nullptr은 무엇인지 조사하시오

NULL은 정수 값 0으로 정의되어 있어 정수와 포인터를 구분하지 못하는 문제가 있고 이로 인해 함수 오버로딩 시 모호성이 발생할 수 있다. 
반면 ``nullptr``은 std::nullptr_t 타입을 가지는 포인터 전용 값으로 포인터로만 인식되어 타입 안정성이 높고 의도치 않은 오류를 방지할 수 있다.
예를 들어, 함수 오버로딩(같은 이름의 함수를 매개변수의 타입이나 개수를 다르게 하여 여러 개 정의하는 것)에서 NULL을 사용할 경우 정수형 함수가 호출될 수 있지만, ``nullptr``을 사용하면 포인터형 함수가 정확하게 호출된다. 따라서 현대에서는 NULL 대신에 ``nullptr``를 주로 사용한다.
