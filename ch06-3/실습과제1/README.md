# 실습과제

## 1. static 멤버변수는 클래스 선언부에 선언하고 외부에서 다시 선언하는 이유를 설명하라.      
       
클래스 선언부에서는 단지 "이 클래스에 이런 ``static`` 변수가 있다"는 존재를 알려주는 선언만 한다.    
하지만, ``static`` 멤버변수는 특정 객체에 종속되지 않고 클래스 전체가 공유하는 단 하나의 변수이기 때문에     
실제 메모리에 공간을 할당해야 한다.          
따라서 클래스 외부에서 다시 정의(선언이 아니라 정의)를 해줘야 메모리에 할당되고 사용할 수 있다.

---

## 2. static 멤버변의 클래스 구현부에 static 키워드를 붙이면 안되는 이유를 설명하라.     

구현부에 ``static``을 붙이면 컴파일러는 이를 클래스 멤버 함수의 정의가 아닌 파일 내부에서만 유효한 별개의         
전역 함수로 해석하게 된다. 결과적으로 클래스 멤버 함수의 실체가 존재하지 않게 되어 링크 에러가 발생한다.
