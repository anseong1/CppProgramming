# 실습과제

## 1. string 객체는 문자열 입력 받을 때 몇 자를 입력할지 물어 보지않고 알아서 크기를 자동 조절한다. 동작 원리를 검색해보고 설명하라

C++의 string 객체는 문자열을 입력받을 때 입력 길이를 미리 물어보지 않아도 된다. 왜냐하면 string이 내부적으로 동적 메모리 할당 방식을 사용하기 때문이다. string 객체는 힙(heap) 영역에 문자 데이터를 저장하는 배열을 가지고 있으며 처음에는 일정한 크기의 메모리를 확보해 놓는다. 이후 사용자가 문자열을 입력하면 그 공간에 데이터를 저장한다.  
이때 string은 실제 저장된 문자열 길이를 나타내는 size와 현재 확보된 메모리 크기인 capacity를 따로 관리한다. 만약 입력된 문자열의 길이가 현재 확보된 메모리 크기를 넘어서게 되면 string 객체는 더 큰 메모리를 새로 할당하고 기존 데이터를 복사한 뒤 이전 메모리를 해제한다. 이 과정을 통해 문자열 크기를 자동으로 확장할 수 있다.  
또한 성능을 고려하여 메모리를 조금씩 늘리는 것이 아니라 보통 기존 크기의 약 2배 정도로 확장하는 방식을 사용한다. 이를 통해 불필요한 메모리 재할당 횟수를 줄이고 효율성을 높인다.  

**<동작원리를 정리하자면 아래 순서와 같다>**
| 단계 | 동작 |
|------|------|
| 1 | 처음에 일정 크기의 메모리 할당 |
| 2 | 문자열 입력 시 메모리에 저장 |
| 3 | 공간 부족 발생시 |
| 4 | 더 큰 메모리 새로 할당 |
| 5 | 기존 데이터 복사 |
| 6 | 이전 메모리 해제 |
| 7 | 자동으로 크기 증가 |

## 2. 문자열을 입력할 때 마지막에 입력하는 엔터키와 getline 함수의 마지막 인자에 전달하는 구분문자와 차이를 설명하라

엔터키(``\n``)는 단순히 사용자가 입력을 마쳤다는 신호로서 입력 버퍼에 저장된다. ``getline()``이 기본값으로 ``\n``을 구분문자로 사용할 때 ``\n``을 만나면 읽기를 멈추고 ``\n``은 버퍼에서 제거하지만 문자열에는 포함시키지 않는다.
반면 ``getline()``의 구분문자를 ``','``처럼 다른 문자로 지정하면 그 문자를 만날 때까지 ``\n``을 포함한 모든 문자를 문자열에 담는다. 즉, 엔터를 눌러도 멈추지 않고 계속 읽는다.  
결론적으로 엔터키는 사용자가 입력을 끝냈다는 물리적 신호이고 ``getline()``의 구분문자는 프로그램이 어디서 읽기를 멈출지 결정하는 논리적 기준이다.
