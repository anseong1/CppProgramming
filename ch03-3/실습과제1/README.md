# 실습과제

## 1. 객체의 생성과 소멸의 의미를 설명하라
객체는 클래스를 기반으로 생성되는 프로그램 내의 실체이다. 객체의 생성은 프로그램 실행 중 해당 객체를 위해 메모리 공간이 할당되고 초기화가 이루어지는 과정을 의미한다. 이 과정에서 생성자가 호출되어 객체의 초기 상태를 설정한다.

객체의 소멸은 함수가 종료되거나 프로그램이 끝날 때 할당받았던 메모리 공간을 OS에 반납하고 더 이상 그 공간을 사용할 수 없게 되는 것을 의미하며 이때 소멸자가 자동으로 호출되어 메모리 해제 등의 마무리 작업이 이루어진다.

---

## 2.  지역변수(지역객체), 전역변수(전역객체)의 차이를 조사하라, 선언위치, 접근범위, 생성시점, 소멸시점, 초기화 여부 등의 관점에서 비교하라 
지역변수는 함수 내부에 선언되어 해당 함수 안에서만 접근 가능하고 함수가 호출될 때 생성되어 함수가 종료될 때 소멸된다. 초기화를 따로 하지 않으면 쓰레기 값이 들어가게 된다. 반면, 전역변수는 함수 외부에 선언되어 프로그램 어디서든 접근 가능하고 프로그램이 시작될 때 main 함수 실행 전에 생성되어 프로그램이 완전히 종료될 때 소멸된다. 초기화를 따로 하지 않으면 자동으로 0으로 초기화가 된다. 

지역객체와 전역객체도 이와 동일한 차이를 가지며 변수 대신 생성자와 소멸자가 호출된다는 점만 다르다. 여기서 알아야 할 점은 지역변수는 주로 스택 영역에 저장되며 전역변수는 데이터 영역에 저장된다는 것이다.

## 3. 프로그램 실행 후 main함수가 실행되기 전에 어떤 일이 처리되는지 조사해보아라
프로그램이 실행되면 곧바로 main 함수가 실행되는 것이 아니라 OS로부터 스택, 힙, 데이터, 코드 영역의 메모리를 할당받습니다. 그 후 Cpp 런타임 라이브러리가 초기화되면서 `cin`, `cout` 같은 표준 입출력 스트림과 메모리 관리자가 준비된다. 이어서 전역 변수와 정적 변수`static`가 선언된 순서대로 초기화되고 전역 객체들도 선언된 순서대로 생성자가 호출된다. 마지막으로 명령줄 인자 준비되며 이 후 amin함수가 실행된다.

---

## 4. main함수가 종료 후 프로그램이 종료하기 전에 어떤 일이 처리되는지 조사하라
main 함수의 실행이 종료된 이후에도 프로그램은 즉시 종료되지 않고 일정한 정리 과정을 거친다. 먼저 main 함수 내부에서 생성된 지역 객체들이 소멸되며 이 과정에서 소멸자가 호출된다. 그 다음 전역 객체들이 생성된 역순으로 소멸된다. 프로그램 종료 시 실행하도록 등록된 함수들이 호츨되고 마지막으로 운영체제가 프로그램이 사용하던 메모리와 자원을 회수한다. 이 후 프로그램이 종료된다.
