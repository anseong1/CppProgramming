# 실습과제

## 1. 객체의 생성과 소멸의 의미를 설명하라

객체는 클래스를 기반으로 생성되는 프로그램 내의 실체이다. 객체의 생성은 프로그램 실행 중 해당 객체를 위해 메모리 공간이 할당되고 초기화가 이루어지는 과정을 의미한다. 이 과정에서 생성자가 호출되어 객체의 초기 상태를 설정한다.

객체의 소멸은 객체의 사용이 끝났을 때 메모리에서 제거되는 과정을 의미한다. 이때 소멸자가 호출되며, 객체가 사용하던 자원이 정리되고 메모리가 해제된다. 객체는 생성 이후 필요한 작업을 수행하다가 더 이상 필요하지 않으면 소멸되는 생명주기를 가진다.

## 2.  지역변수(지역객체), 전역변수(전역객체)의 차이를 조사하라, 선언위치, 접근범위, 생성시점, 소멸시점, 초기화 여부 등의 관점에서 비교하라 
지역변수는 함수 내부에서 선언되는 변수로, 해당 함수 내부에서만 접근이 가능하다. 함수가 호출될 때 생성되며, 함수 실행이 끝나면 자동으로 소멸된다. 따라서 생명주기가 짧고, 일시적인 데이터를 저장하는 데 적합하다.

반면 전역변수는 함수 외부에서 선언되며, 프로그램 전체에서 접근이 가능하다. 프로그램이 시작될 때 생성되고, 프로그램이 종료될 때까지 유지된다. 또한 전역변수는 별도의 초기값을 지정하지 않으면 자동으로 0으로 초기화된다.

지역변수는 주로 스택 영역에 저장되며, 전역변수는 데이터 영역에 저장된다.

## 3. 프로그램 실행 후 main함수가 실행되기 전에 어떤 일이 처리되는지 조사해보아라

프로그램이 실행되면 곧바로 main 함수가 실행되는 것이 아니라, 그 이전에 여러 초기화 과정이 수행된다. 먼저 실행 파일이 메모리에 로드되며, 프로그램이 실행될 준비가 이루어진다.

그 다음으로 전역 변수와 정적 변수들이 초기화된다. 이때 초기값이 지정되지 않은 변수들은 자동으로 0으로 초기화된다. 이후 전역 객체 및 정적 객체가 생성되며, 이 과정에서 생성자가 호출된다.

또한 프로그램 실행에 필요한 런타임 환경이 설정되며, 스택과 힙 영역이 준비된다. 이러한 모든 과정이 완료된 이후에 main 함수가 호출되어 본격적인 프로그램 실행이 시작된다.

---

## 4. main함수가 종료 후 프로그램이 종료하기 전에 어떤 일이 처리되는지 조사하라
main 함수의 실행이 종료된 이후에도 프로그램은 즉시 종료되지 않고 일정한 정리 과정을 거친다. 먼저 main 함수 내부에서 생성된 지역 객체들이 소멸되며, 이 과정에서 소멸자가 호출된다.
그 다음으로 전역 객체들이 생성된 역순으로 소멸된다. 이후 프로그램 종료 시 실행하도록 등록된 함수들이 호츨되고 마지막으로 운영체제가 프로그램이 사용하던 메모리와 자원을 회수한다. 이 후 프로그램이 종료된다.
