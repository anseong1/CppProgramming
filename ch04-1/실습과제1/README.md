# 실습과제

## 1. 배열명의 의미를 설명하라.
배열명은 배열의 첫 번째 요소를 가리키는 고정된 주소값(포인터 상수)이라고 할 수 있다.

- 배열을 선언하면 메모리에 여러 개의 값이 연속적으로 저장된다.
- 이때 배열명은 그 중 첫 번째 요소의 주소를 가리킨다.
- 그래서 배열명은 일종의 포인터처럼 사용될 수 있다.

---

## 2. 객체 포인터의 의미를 설명하라.
객체 포인터는 객체의 메모리 주소를 저장하여 해당 객체의 멤버에 간접적으로 접근할 수 있게 해주는 포인터 변수이고
`->` 연산자로 멤버에 접근 가능하다.

---

## 3. 포인터를 이용하여 배열 각 원소의 주소를 구하는 방법을 설명하라
배열의 각 원소 주소를 포인터로 구하는 방법은 배열명이 곧 첫 번째 원소의 주소라는 사실을 이용하고 포인터에 배열명을 대입한 후 인덱스만큼 더하는 방식으로 배열 각 원소의 주소를 순차적으로 구할 수 있으며 이때 주소는 바이트 크기가 아니라 자료형 크기 단위로 이동한다. 결국 `p + i는 arr[i]`의 주소와 같다고 할 수 있다.

---

## 4. 포인터를 이용하여 배열 각 원소의 값을 구하는 방법을 설명하라
포인터에 배열명을 대입한 후 역참조 연산자 `*`와 포인터 연산을 함께 사용하면 배열 각 원소의 값을 순서대로 구할 수 있습니다. 

총 정리를 하자면 아래 표와 같다.
| 구분 | 문법 | 예시 |
|------|------|------|
| 일반 객체 | `.` 연산자 | `p.name` |
| 객체 포인터 | `->` 연산자 | `ptr->name` |
| 역참조 후 접근 | `(*ptr).` | `(*ptr).name` |
