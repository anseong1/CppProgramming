# 실습과제 


## 1. 인자와 매개변수를 구분하여 설명하시오.
**매개변수(Parameter)**      
매개변수는 함수를 정의할 때 선언하는 변수이다. 
     
**인자(Argument)**     
인자는 함수를 호출할 때 실제로 전달하는 값이다.

---

## 2. 함수 호출시 자동으로 처리되는 2가지는 무엇인가?
첫째, 인자 값을 매개변수에 복사호출 시 인자의 값이 매개변수에 자동으로 대입된다.    
둘째, 호출한 위치(복귀 주소)를 스택에 저장 함수 실행이 끝난 후 돌아올 위치를 자동으로 저장한다.

---

## 3.  값에 의한 호출로 다른 함수에서 선언된 변수의 값을 변경할 수 없다. 이유를 설명하라.
값에 의한 호출은 인자의 값만 복사하여 매개변수에 전달하기 때문이다. 매개변수는 호출된 함수의 스택에 별도로 생성된 독립적인 지역 변수이기 때문에 값을 바꿔도 원본 변수와는 전혀 다른 메모리 공간을 가리킨다. 따라서 원본 변수는 변경되지 않는다.

---

## 4. 주소에 의한 호출을 사용해야하는 경우를 2가지 이상 설명하라.
첫째, 호출한 함수의 변수 값을 직접 변경해야 할 때     
둘째, 함수에서 여러 개의 값을 반환해야 할 때 ``return``은 하나의 값만 반환하므로, 여러 결과를 돌려줄 때 참조/포인터를 사용한다.   
셋째, 크기가 큰 데이터를 복사 비용 없이 전달할 때 대형 구조체나 배열을 복사하면 비효율적이므로 주소만 전달한다.    

---

## 5. 인자가 객체인 경우는 어떤 호출방식이 좋은가? 이유도 설명하라.
주소에 대한 호출이 더 좋다. 왜냐하면 객체는 크기가 크기 때문에 값으로 전달하면 객체 전체가 복사되어 메모리와 시간이 낭비된다. 주소로 전달하면 주소값(포인터)만 전달되어 효율적이다. 반대로 값에 의한 호출은 매개변수 생성 과정에서 복사 생성자가 자동 호출되는데 이는 부작용을 일으킬 수 있다.
수정이 필요 없으면 ``const`` 포인터로 전달하여 원본 객체를 보호하는 것이 좋다.

---

## 6. 함수 반환과정에서 자동으로 처리되는 2가지는 무엇인가?
첫째, 지역 변수(매개변수 포함) 소멸 함수의 스택 프레임이 해제되면서 함수 내부에서 선언된 모든 지역 변수가 자동으로 제거된다.  
둘째, 저장된 복귀 주소로 제어 흐름 이동 스택에 저장해 두었던 복귀 주소로 자동으로 돌아가 호출한 함수의 다음 문장을 실행한다.    

---

## 7. 함수 반환과정에서 임시변수가 필요한 이유를 설명하라.
함수가 값을 반환할 때 반환값을 담아둘 임시 공간이 필요하기 때문이다.    
반환하려는 지역 변수는 함수가 끝나는 순간 스택에서 소멸된다. 그런데 호출한 쪽에서 그 값을 받아야 하므로 소멸되기 전에 임시 변수에 값을 복사하고 스택이 정리된 후 호출자에게 전달하는 것이다.
